Подключение к VPN

__SERVER_TITLE__ · пошаговая инструкция для iPhone, Android, Windows, macOS и Linux

1. Скачать свой профиль

Введите имя профиля, которое вам сообщил администратор.

Ссылки одноразовые и действуют ограниченное время — если не успели скачать, запросите заново.

2. Какой профиль выбрать

Профилей два, они отличаются тем, какой трафик уходит через VPN. Рекомендуем добавить в приложение оба — они не мешают друг другу, но одновременно работает только один.

РЕКОМЕНДУЕТСЯ

AntiZapret

«Умный» режим: через VPN идут только заблокированные сайты и сервисы, всё остальное открывается напрямую, как обычно.

  • Выше скорость — обычные сайты грузятся напрямую
  • Банки, госуслуги и локальные сервисы работают как обычно
  • Сайты видят вашу настоящую страну
  • Минус: если сайт заблокирован «нестандартно», он может не открыться
ДЛЯ ОСОБЫХ СЛУЧАЕВ

VPN (полный)

Весь интернет-трафик идёт через сервер VPN, независимо от адреса назначения.

  • Работает с любым сайтом и приложением
  • Провайдер не видит, какие сайты вы открываете
  • Минус: скорость обычно ниже, российские сервисы (банки, госуслуги) могут не работать
На практике: повседневно держите включённым AntiZapret. Если какой-то сайт не открывается — выключите его и включите VPN.

3. Установка

  1. Установите из App Store приложение OpenVPN Connect (значок — оранжевый щит).
  2. Сохраните оба файла профиля на устройство: после скачивания нажмите «Поделиться» → «Сохранить в Файлы».
  3. Откройте приложение Файлы, нажмите на файл .ovpn и выберите «Поделиться» → OpenVPN.
  4. В открывшемся приложении нажмите ADD (или IMPORT).
  5. Если запрашивается логин и пароль — введите их и включите переключатель Save password.
  6. iOS попросит разрешение на добавление конфигурации VPN — нажмите Allow и подтвердите код-паролем или Face ID.
  7. Повторите шаги 3–5 для второго профиля.
  8. Для подключения включите переключатель рядом с нужным профилем. Вверху экрана появится значок VPN.
  1. Установите из Google Play приложение OpenVPN Connect.
  2. Скачайте оба файла профиля — обычно они попадают в папку «Загрузки».
  3. Откройте приложение, перейдите на вкладку FILE и нажмите BROWSE. Разрешите доступ к файлам, если система спросит.
  4. Выберите файл .ovpn и нажмите IMPORT.
  5. Введите логин и пароль, если требуются, отметьте Save password.
  6. На запрос «Разрешить создание VPN-подключения?» нажмите OK.
  7. Повторите шаги 3–5 для второго профиля.
  8. Включите переключатель профиля — в строке состояния появится значок ключа.
Чтобы связь не обрывалась: «Настройки → Приложения → OpenVPN → Батарея» → «Без ограничений».
  1. Откройте openvpn.net/client и скачайте OpenVPN Connect для Windows.
  2. Установите программу, запустите её и примите условия использования.
  3. На вкладке FILE перетащите файл .ovpn в окно программы (или через кнопку BROWSE).
  4. Нажмите CONNECT, при необходимости введите логин и пароль.
  5. Добавьте так же второй профиль — оба будут в списке, переключаться можно одним кликом.
  6. Значок программы в правом нижнем углу станет зелёным, когда подключение установлено.
Если подключение обрывается через несколько секунд — закройте программу и запустите правым кликом → «Запуск от имени администратора».
  1. Скачайте OpenVPN Connect с openvpn.net/client и перетащите в «Программы».
  2. Запустите его и разрешите системное расширение: «Системные настройки» → «Конфиденциальность и безопасность» → Разрешить.
  3. На вкладке FILE перетащите файл .ovpn в окно программы.
  4. Нажмите CONNECT и подтвердите паролем от учётной записи Mac.
  5. Добавьте второй профиль тем же способом. Управлять подключением можно через значок в верхней строке меню.

В графическом интерфейсе: «Настройки» → «Сеть» → VPN → «+» → «Импортировать из файла…» → выберите .ovpn.

Через терминал:

sudo apt install openvpn
sudo openvpn --config /путь/к/profile.ovpn

4. Проверка

Откройте сайт 2ip.ru. При включённом профиле VPN там будет показан адрес и страна сервера, а не вашего провайдера. При включённом AntiZapret адрес останется вашим — это нормально, режим работает правильно; проверять его нужно по доступности заблокированного сайта.

5. Если что-то не работает

Что вы видитеЧто делать
Ошибка AUTH_FAILEDНеверный логин/пароль либо истёк срок действия профиля — запросите новый файл у администратора.
Connecting / TLS handshake failedСеть блокирует соединение. Попробуйте мобильный интернет вместо Wi-Fi.
Подключение есть, но сайты не открываютсяПроблема с DNS — включите DNS Fallback в настройках OpenVPN Connect. На Windows запустите программу от администратора.
Не открывается конкретный сайт или приложениеПереключитесь с AntiZapret на VPN — он пропускает через сервер весь трафик.
Не работают банк, госуслуги, доставкаНаоборот: переключитесь с VPN на AntiZapret либо временно отключите VPN.
На телефоне соединение обрывается самоСнимите ограничения энергосбережения для приложения OpenVPN.
Профиль вообще не подключаетсяУбедитесь, что не включён другой VPN и не активен второй профиль — одновременно работает только один.

Если ничего не помогло — отправьте администратору журнал подключения (в OpenVPN Connect: значок статистики в правом верхнем углу → «Share»/«Поделиться»).
